## 🚀 Features

* Add, edit, and delete goals
* Habit tracking (water intake, study hours)
* Real-time progress dashboard
* Smart insights and streak tracking
* Dark-themed modern UI

## 🛠 Tech Stack

* React
* TypeScript
* Tailwind CSS

```bash
npm install
npm run dev
```
